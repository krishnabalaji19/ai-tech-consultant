# Task 3 — Meeting to Scope

Turns meeting transcripts into requirements, a feasibility check (via Task 1’s API), a scope, hour estimates, and a proposal. A human must approve before anything is “sent.”

**This folder in simple words**

- `app/` — the review screen and API.
- `agents/` — separate steps (extract, feasibility, scope, estimate, proposal).
- `transcripts/` — three practice meetings (one is a follow-up).
- `templates/` — the scope builder page.
- `tests/` — automated checks.

Stage 0: empty placeholders only.
